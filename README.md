# マルチトラック音声エディタ（プロトタイプ）

複数の音声ファイルをそれぞれ別トラックとして読み込み、タイムライン上でトリミング・カット・移動し、
最後に1つの音声ファイルへミックスダウン（結合）して書き出せる、最小構成のWebアプリです。

- フロントエンド: HTML / CSS / Vanilla JavaScript
- バックエンド: Python (Flask + pydub)

## セットアップ

1. Python 3.9以降を用意してください。
2. **ffmpeg** をインストールしてください（pydubが内部で使用します）。
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - Windows: https://ffmpeg.org/download.html からダウンロードし、PATHに追加してください。
3. 依存パッケージをインストール:
   ```bash
   cd "プロジェクトのカレントディレクトリ"
   pip install -r requirements.txt
   ```
4. サーバーを起動:
   ```bash
   python app.py
   ```
5. ブラウザで `http://127.0.0.1:5000` を開いてください。

## 使い方

1. 「+ ファイルを追加」から音声ファイル（mp3 / wav / m4a / flac など）を複数選択します。
   ファイルごとに新しいトラック（行）が追加されます。
2. **移動**: クリップ本体をドラッグすると、タイムライン上の開始位置を変更できます。
3. **トリミング**: クリップの左右の端をドラッグすると、再生範囲を非破壊的に調整できます。
4. **カット**: ルーラー（時間軸）をクリックして再生ヘッドをクリップの途中に置き、
   対象クリップを選択した状態で「✂ カット」を押すと、その位置で2つのクリップに分割されます。
5. **削除**: クリップを選択して「🗑 削除」で削除できます。
6. **再生**: 再生ヘッド位置から全トラックを同時に試聴できます（「▶ 再生」/「■ 停止」）。
7. **書き出し（結合）**: 「⬇ 書き出し(結合)」を押すと、現在のタイムライン配置に基づいて
   全トラックをミックスダウンした1つの音声ファイル（WAV/MP3選択可）が書き出されます。
   Chrome / Edge など対応ブラウザでは、書き出し前に保存先（フォルダ・ファイル名）を選択できます。
   Firefox / Safari など非対応ブラウザではブラウザの通常のダウンロード機能で保存されます。
   いずれの場合も、書き出したデータの取得が完了した時点でサーバー上の一時ファイルは自動的に削除されます。

## 制限事項（プロトタイプのため）

- トラック間でのクリップ移動（行をまたぐドラッグ）には対応していません。
- 音量調整・フェードイン/アウトには対応していません。
- 保存・再読み込み（プロジェクトファイル化）には対応していません。ページを再読み込みすると編集内容は失われます。
- アップロードした元ファイルはサーバー上の `uploads/` に保存されます。トラックの🗑ボタン、または
  「🧹 音源を全削除」から削除できます。
- 書き出し結果はサーバー上の `exports/` に一時的に保存されますが、ブラウザ側での取得が完了すると
  自動的に削除されます（処理が失敗した場合など、まれに残ることがあります）。
- 書き出し時の保存先指定は File System Access API に対応したブラウザ（Chrome / Edgeなど）のみの機能です。
  対応していないブラウザでは、ブラウザの既定のダウンロード先に保存されます。
